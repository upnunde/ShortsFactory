# 뉴스 원본 쇼츠 편집 모드

## 분리 구조

- `/studio/character`: 기존 캐릭터·AI 생성형 쇼츠
- `/studio/news-clips`: 원본 뉴스 영상 재편집
- 프로젝트 타입: `character`, `news_clip`

뉴스 모드는 기존 `Project`, 캐릭터 채널 프로필, 캐릭터 씬, 힙스필드 파이프라인을 사용하지 않는다. 아나운서 보도 대본과 TTS를 기준으로 자료 영상을 조립하되, 직접 발언 장면은 원본 영상과 음성으로 전환한다. FFmpeg 실행 유틸리티만 공통으로 사용한다.

채널 목록도 제작 모드별로 분리한다.

- 캐릭터 채널: `config/profiles`, `config/channels`
- 뉴스 채널: `config/news-channels/{newsChannelId}`
- 캐릭터 채널을 만들어도 뉴스 목록에 나오지 않고, 뉴스 채널을 만들어도 캐릭터 목록에 나오지 않는다.
- 채널 설정, 로컬 프로젝트 키, 프레임·로고·BGM 자산도 뉴스 채널 ID 기준으로 저장한다.

## 필요한 실행 설정

플랫폼 첫 화면의 `플랫폼 설정`에서 다음 API를 공통으로 등록한다.

- Claude: 보도 대본과 화면 연출
- YouTube Data API: 최근 원본 뉴스 검색

제목과 아나운서 TTS는 한국어 전용 오픈소스 `Xenova/mms-tts-kor` 모델을 로컬
ONNX로 실행하므로 API 키와 사용료가 필요하지 않다. 첫 실행에서 모델을 한 번
내려받으며 이후에는 로컬 캐시를 사용한다. 뉴스 채널 설정에서 시스템 한국어
음성을 예비 옵션으로 선택하거나 실제 문장을 미리 들을 수 있다.

뉴스 채널 설정의 `우선 탐색 주제`에는 필수 포함 키워드가 아니라 찾고 싶은
내용의 방향을 자연어로 적는다. 이 설명은 Google News 검색어 확장과 이슈 추천
관련도 가산에 사용하며, 표현이 정확히 일치하지 않는 기사를 강제로 제외하지
않는다.

기존 설치의 환경변수도 계속 읽지만, 새 키는 채널 설정이 아니라 플랫폼 공통 설정에 저장한다.

```bash
# 선택 사항: 기존 환경변수 방식과 로컬 도구 설정
YOUTUBE_DATA_API_KEY=...
AZURE_SPEECH_KEY=...
AZURE_SPEECH_REGION=koreacentral

# 자막이 없는 원본의 로컬 음성 인식
WHISPER_BIN=whisper
WHISPER_MODEL=small

# 승인한 YouTube 원본과 제공 자막을 한 번만 저장
# 미설정 시 프로젝트 내부 .tools/yt-dlp를 우선 사용
YTDLP_BIN=yt-dlp
```

Claude 키는 `config/credentials/anthropic.json`을 플랫폼 공통으로 읽는다. Claude를 사용할 수 없으면 로컬 점수와 원문을 사용해 초안을 만든다.

## 제작 흐름

화면에서는 산출물과 승인 책임이 겹치지 않도록 다음 6단계로 구분한다.

1. `이슈 탐색·승인`: Google News RSS의 최근 웹 기사와 선택적 공개 커뮤니티 신호에서 추천 이슈 5개를 제시하고, 사용자가 제작할 주제를 결정한다. 이 단계는 YouTube API를 사용하지 않는다.
2. `원본 영상 선택`: 승인한 이슈를 YouTube 전체에서 검색해 원본 후보 5개를 제시한다. 우선 검색 채널은 선택 사항이며, 등록하면 해당 채널 결과에만 추천 가산점을 준다. 사용자가 원본 하나를 승인하면 그 영상만 다운로드·전사·음성 분석한다.
3. `보도 대본 검수`: AI가 전체 녹취를 근거로 작성한 제목과 아나운서 보도문을 검수하고 최종 낭독 문장을 확정한다.
4. `화면 연출 구성`: 문장마다 TTS가 이어지는 자료 화면 또는 원본 음성 직접 발언을 선택하고 자료 타임코드를 확정한다. 승인하면 540×960 저해상도 초안을 생성한다.
5. `초안 검수·수정`: 실제 초안을 재생하며 컷, 제목, 자막, 강조 단어, 화면 위치, BGM과 음량을 수정한다. 45~58초 조건을 만족한 초안만 승인할 수 있다.
6. `최종 제작·결과`: 초안 승인 후에만 1080×1920 최종본을 렌더하고 영상과 썸네일을 확인한다.

사이드바의 1~6단계는 선행 작업 여부와 관계없이 모두 열어볼 수 있다. 다만 실제 초안·최종 렌더 버튼은 필요한 대본, 연출, 길이 조건과 이전 생성 결과가 갖춰졌을 때만 실행된다.

검색 점수는 게시 후 시간 대비 조회수 35점, 댓글 반응 25점, 교차 채널 20점, 최근성 10점, 직접 발언 가능성 10점으로 계산한다. 채널별 최근 영상 반응과 비교해 채널 규모를 정규화한다.

## 공개 커뮤니티 보조 신호

- 채널 설정에서 켜고 끄며, 로그인 없이 접근 가능한 일베 공개 게시판만 사용한다.
- 기본 30분 캐시로 저빈도 접근하며 로그인·캡차·차단을 우회하지 않는다.
- 반복되는 인물·정책·사건만 중립 표현으로 묶고, 등록 뉴스 채널의 실제 영상 검색에만 쓴다.
- 커뮤니티 글은 사실 확인 근거나 영상 원본으로 사용하지 않는다.

## 자동 편집 기준

1. 기존 SRT/VTT를 우선하고 없으면 로컬 Whisper를 실행해 사실 근거와 자료 타임코드를 확보한다.
2. Claude는 원문 밖의 사실을 추가하지 않고 5~7문장의 중립적인 아나운서 보도 대본을 작성한다.
3. 제목과 일반 본문은 같은 아나운서 음성을 사용하며, 본문 TTS는 문장별로 생성한다.
4. 일반 문장은 실제 TTS 길이, 직접 발언은 선택한 원본 구간 길이가 화면 전환과 자막 타임코드의 기준이다.
5. `source` 자료 화면은 원본을 음소거하고 아나운서 보도를 이어간다. `quote` 직접 발언은 아나운서 TTS를 멈추고 원본 영상과 음성을 함께 재생한다.
6. 제목 프레임을 포함한 최종 길이는 45~58초, 우선 목표는 50~55초로 맞춘다. 59초 이상은 렌더 요청을 거부한다.
7. 길이는 대본의 핵심도가 낮은 문장을 삭제하거나 근거 설명을 보강해 조정하며 음성을 부자연스럽게 배속하지 않는다.

## 출력

`public/news-clips/output/{projectId}`에 다음을 생성한다.

- `preview.mp4`: 수정 검수용 540×960 저해상도 초안
- `final.mp4`: 1080×1920, H.264/AAC
- `captions.srt`: 외부 자막
- `captions.ass`: 강조 단어 색상 포함 렌더용 자막
- `title-frame.png`, `thumbnail.png`
- `manifest.json`: 원본 URL, 사용 타임코드, 무음 삭제 구간, 점수와 선정 이유
- `youtube-metadata.json`: 제목·설명·태그 초안

원본 업로드와 생성 영상은 Git에 추가되지 않도록 ignore 처리한다.

`outputs/news-clips/{sourceId}`에 승인 원본, 전체 자막, 단어 타임코드와 Claude 보도 대본을 캐시한다. `보도 대본 다시 작성`을 눌러야만 Claude를 다시 실행한다. 렌더러는 제목·문장별 TTS·본문·BGM 서브 결과의 서명을 따로 보관해 변경되지 않은 부분을 재사용한다.
