# 화면 구성 확인 UI 재설계

날짜: 2026-11-07  
상태: 승인 대기 (구현 전 스펙)

## 문제

현재 「화면 구성」은 영상 전체를 하나의 전역 크롭으로 다루고, 모든 문장 카드에 자료/종류/구간 컨트롤을 항상 펼쳐 둔다.  
이 UI를 둔 본래 목적은 **구간마다 프레이밍이 이상하지 않은지 확인·보정**하는 것이지, 통째 연출 편집기가 아니다.

별도 「인트로」 탭도 같은 확인 목적의 화면 구성인데, 화면 구성과 분리되어 있다.

자동 프레이밍 완성도는 아직 검증되지 않았다. 확인 UI를 없애기엔 이르고, 풀 연출 패널로 키우기엔 과하다.

## 목표

1. 화면 구성을 **확인용**으로 재정렬한다.
2. **인트로 | 본문** 탭으로 한곳에 모은다.
3. 본문은 **구간 선택 시에만** 보정 컨트롤을 노출한다.
4. 자동 프레이밍 고도화는 이번 범위 밖이다. 기존 기본값을 유지한다.

## 비목표

- 씬별 crop 데이터 모델 / 렌더 반영 (1차 제외)
- 자동 얼굴·화자 트래킹 고도화
- 자료 선택·화면 종류(source/quote)를 이 화면의 주 컨트롤로 유지
- direction 모드 전체 재설계 (preview의 화면 구성 중심)

## 정보 구조

### 에디터 탭 (preview)

| 변경 전 | 변경 후 |
|--------|--------|
| 제목·대본 / **인트로** / 자막 / 화면 구성 / 음향 | 제목·대본 / 자막 / **화면 구성** / 음향 |

- 독립 `intro` 에디터 탭 제거
- `scenes`(=화면 구성) 안에 서브탭: **인트로 | 본문**

### 좌측 미리보기

- 화면 구성 > 인트로 선택 → `frameMode = title`, 인트로 스틸 프리뷰
- 화면 구성 > 본문 선택 → `frameMode = body`, 선택된 구간(없으면 첫 구간) 시점으로 시크
- 기존 preview의 「인트로|본문」 전환과 화면 구성 서브탭을 같은 상태로 묶는다

## 인트로 탭

기존 인트로 카드 기능을 그대로 이전한다.

- 스틸 시점 타임라인
- 확대 / 좌우·위아래 위치
- 자동 선택 복원
- 미리보기는 타이틀 프레임

## 본문 탭

### 리스트 (항상)

각 `reportScenes` 항목을 한 줄(또는 짧은 카드)로 나열한다.

- 라벨: 문장/구간 번호 + 나레이션 요약(1줄)
- 배지: `자료` / `직접발언` (읽기 전용 표시)
- 선택 시 하이라이트 + 좌측 본문 프리뷰를 해당 `sourceStart`로 이동

### 「전체 화면 설정」 제거

전역 크롭 슬라이더를 본문 상단에 항상 두던 블록을 없앤다.

### 선택 시에만 노출되는 보정 UI

선택된 구간에 대해:

1. **프레이밍** — `crop.zoom` / `crop.x` / `crop.y`  
   - 1차: 기존 프로젝트 전역 `crop`을 수정한다.  
   - 선택 구간을 보며 맞추는 확인 흐름이며, 저장값은 전역 1세트다.
2. **자료 구간** — 기존 `SourceRangeTimeline` (`sourceStart` / `sourceEnd`)

노출하지 않음 (본 화면):

- 사용 자료 select
- 화면 종류 select  

(필요하면 이후 연출 전용 흐름으로 분리. 확인 UI 복잡도에서 제외.)

선택 해제 또는 다른 구간 선택 시, 이전 구간의 보정 UI는 접힌다.

## 데이터

### 1차 (이번 스펙)

변경 없음.

- `NewsClipProject.crop` — 본문 프레이밍 1세트
- `NewsClipProject.introStill*` — 인트로
- `NewsReportScene.sourceStart/End` — 구간별 타임라인만 씬에 유지

### 의도적 보류

씬별 `crop` 필드와 렌더 반영은 자동 프레이밍 검증 이후, “구간마다 다른 구도가 실제로 필요”가 확인되면 별 스펙으로 추가한다.

## UX 규칙

- 안내 문구 최소화 (프로젝트 UI 규칙 유지). 카드 제목·탭 라벨 위주.
- 컨트롤은 선택 맥락에서만 나타난다.
- direction 모드의 화면 구성이 남아 있다면, preview와 동일한 **본문 구간 선택 → 보정 노출** 패턴을 따른다. 인트로 서브탭은 preview에서만 의미 있다.

## 구현 경계 (예상 파일)

- `components/news-clips/review-step.tsx` — 탭 구조, 인트로 이전, 본문 선택형 컨트롤
- (필요 시) 작은 서브컴포넌트 분리 — 같은 파일 비대화 시에만

렌더·타입·자동 프레이밍 로직은 1차에서 건드리지 않는다.

## 성공 기준

1. preview에서 독립 인트로 탭이 없고, 화면 구성 > 인트로에서 동일 보정이 가능하다.
2. 본문에서 구간을 고르기 전에는 크롭·타임라인 슬라이더가 보이지 않는다.
3. 구간 선택 후 프레이밍·구간을 바꾸면 미리보기에 반영되고, 기존처럼 프로젝트 상태에 저장된다.
4. 「전체 화면 설정」 상시 블록이 없다.

## 테스트

- 수동: preview에서 인트로/본문 서브탭 전환, 구간 선택·해제 시 컨트롤 노출, 크롭·구간 변경 후 미리보기
- 자동: 이번 UI 재배치만이면 단위 테스트 필수 추가 없음. 기존 review 관련 테스트가 탭 id에 묶여 있으면 갱신
