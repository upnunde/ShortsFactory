# 4번 미리보기·최종·예약 업로드

날짜: 2026-11-07  
상태: 구현됨

## 플로우

| 사이드바 | 내부 step | 역할 |
|---------|-----------|------|
| 3 | `preview` | 검수·수정만 (대본·자막·화면구성·음향). 렌더된 초안 시청 UI 없음. 「미리보기 만들기」로 초안 생성 후 4로 이동 |
| 4 | `final` | 초안 미리보기 → 최종본 변환(같은 페이지) → YouTube 예약 업로드 |

## 4번 UI

1. 미리보기 재생 (`previewUrl`). 「미리보기 다시 만들기」
2. 「최종본으로 변환」 → `final.mp4` 생성·재생. 「다시 만들기」 가능
3. YouTube: 예약 날짜·시간(`datetime-local`, KST) 선택 후 업로드. `publishAt` 사용

맘에 안 들면 이전(3번)으로 가 수정 후 다시 만들기.
