# 영상 프레임 배치 및 렌더링 설계

## 목표

설정 화면에서 영상 배치 방식을 선택하고, 선택한 제목·자막 위치가 최종 MP4에 실제로 반영되게 한다.

## 배치 모드

### 전체 화면

- 9:16 영상은 잘라내지 않고 전체 프레임에 표시한다.
- 영상 비율이 다를 경우 비율을 유지한 채 프레임 안에 맞추고 남는 영역만 여백으로 처리한다.
- 제목과 자막은 영상 위에 오버레이한다.
- 제목과 자막은 각각 가로·세로 위치를 0~100 범위로 조정한다.

### 영역 분할

- 기존 제목·영상·자막의 세 영역 구조를 유지한다.
- 제목과 자막 높이를 조절하며 영상은 남은 영역을 사용한다.
- 영상은 지정 영역 안에서 비율을 유지하고 잘라내지 않는다.

## 설정 데이터

`FrameLayout`에 다음 값을 저장한다.

- `mode`: `overlay` 또는 `split`
- `titleHeight`, `subtitleHeight`: 영역 분할 모드의 높이
- `titleX`, `titleY`: 전체 화면 모드 제목 위치
- `subtitleX`, `subtitleY`: 전체 화면 모드 자막 위치

기존 설정에 `mode`와 위치 값이 없으면 기본값을 적용해 이전 파일과 호환한다. 기본 모드는 `overlay`다.

## 설정 UI

- 전체 화면과 영역 분할을 선택하는 컨트롤을 제공한다.
- 전체 화면 모드에서는 제목·자막의 X·Y 슬라이더를 표시한다.
- 영역 분할 모드에서는 기존 높이 슬라이더를 표시한다.
- 9:16 미리보기는 저장될 실제 배치를 반영한다.

## 렌더링

- 영상 작업 시작 시 서버가 저장된 프레임 설정을 읽는다.
- 전체 화면 모드는 원본 영상의 비율을 유지해 9:16 프레임에 맞춘다.
- 영역 분할 모드는 계산된 영상 영역 안에 원본을 맞춘다.
- 프로젝트 주제를 제목으로 사용한다.
- 각 장면의 영어 자막과 장면 지속 시간을 이용해 자막 이벤트를 만든다.
- FFmpeg가 제목과 자막을 최종 MP4에 합성한다.
- 이후 Kokoro TTS가 연결되면 장면 추정 시간 대신 실제 단어 타임스탬프를 사용한다.

## 오류 처리와 검증

- 잘못된 숫자는 기본값으로 대체하고 모든 위치 값은 0~100으로 제한한다.
- 기존 `config/layout.json`을 읽어도 오류가 발생하지 않아야 한다.
- 설정 정규화와 영상 필터 구성을 자동 테스트한다.
- 타입 검사, 린트, 프로덕션 빌드를 확인한다.
